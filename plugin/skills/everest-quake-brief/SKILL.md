# 地震与崩塌简报

## 取数

1. `everest_quakes`，`limit` 默认 10；用户要更多就加大（最多 30）。
2. `everest_offline` 看 IO.EVN 地震台（Pyramid）是否停发，停发要写出最后数据时间——台站停发时近场小事件可能漏记。
3. 需要原始数据时用 `everest_source`，`key` 取 `usgs`、`emsc` 或 `nsc`。

## 写法

- 按时间倒序列出：北京时间、震级和类型、位置、来源。
- 同一事件在多个目录里出现时合并成一行，并列出各目录给的震级。
- USGS 类型为 `landslide` 的写“崩塌/滑坡（非构造）”。
- 只陈述目录记录，不推测余震、不评估危险。
