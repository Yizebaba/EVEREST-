# 281 种灾害的实测覆盖

## 取数

1. 有 EVEREST 连接器时：`everest_events`（`full: true`）返回的 `hz` 字段就是最新扫描结果：
   - `hz.src`：每个来源 `[状态, 条数, 本地条数, 错误或缺的密钥, 时效]`；
   - `hz.h`：每种灾害 `[编码, 状态, 本地条数, 90 天条数, 最新时间, 最新标题, 链接, 可用来源数, 时效]`；
   - `hz.by_latency`：各时效的灾种数。
2. 没有连接器时读公开文件：`https://raw.githubusercontent.com/Yizebaba/EVEREST-/events/hazards/scan.json`（每小时更新），逐条对照见仓库 `docs/HAZARDS_281.md`。

## 回答规则

- 状态含义：local 本地有记录、global 外地有记录、observed 只有持续观测、ok_none 来源正常但 90 天无记录、key 需要密钥、fail 来源失败。
- 时效按发布方更新频率分：实时（分钟到 1 小时）、准实时（几小时到 1 天）、定期（每周或更慢）；新闻只是线索，单列。
- 引用记录时给出来源名和链接；新闻标题照原文，不改写成事实陈述。
- 监测回答不说“会不会发生”；需要推演时用 MiroFish，并标注为推演。
