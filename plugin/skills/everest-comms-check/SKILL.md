# 停发排查

## 取数

1. `everest_offline`：停发设备和最后数据时间。
2. `everest_connectivity`：萨加玛塔区 BGP 可达网段和主动探测，24 小时最低值。
3. `everest_satellite_tracking`：DORIS 信标 EVEC 最近被跟踪的时间——信标自带电源和发射机，被跟踪说明当地有电、设备在发射。
4. `everest_air_traffic`：可选，作为卢卡拉一带是否有活动的旁证（0 架不代表没有飞机）。

## 判断写法（只列证据，不下结论）

- 停发时间与断网时间重合 → “可能与当地断网有关”。
- 网络正常而单个站停发 → “更可能是该设备或其上传链路的问题”。
- 停发很久（几周以上）的站 → 提醒去“设备维护”标签登记或查看维修记录。
- 外部设备（尼泊尔水文局水位站、IO.EVN、DORIS）不归本平台维修，只报告状态和联系渠道。
